🏫 DAFTAR SEKOLAH
Isi jumlah siswa, guru, dan tendik — kolom Porsi terhitung otomatis. 🟢/⚪ untuk aktif/nonaktif, ＋ menambah sekolah.
👶 DATA KELOMPOK 3B
Sasaran ibu menyusui, ibu hamil, balita/baduta, dan ibu nifas per desa.
🥄 UJI ORGANOLEPTIK & 💰 HARGA PORSI
Sampel otomatis: TK 1 (kecil), SD 2 (kecil+besar), SMP 2 (besar), SMA 2 (besar), Kelompok 3B 1 besar per desa. Sekolah nonaktif tidak dihitung.
🥗 TARGET NILAI GIZI (AKG)
Acuan pemenuhan gizi per porsi. Angka bawaan hanya perkiraan umum — sesuaikan dengan standar resmi BGN yang berlaku.
🧾 TARIF HONOR PIC
Tarif harian PIC sekolah dibedakan berdasarkan jumlah siswa, serta tarif per orang untuk Kelompok 3B.
📸 DESKRIPSI TAHAPAN KEGIATAN
Keterangan singkat tiap tahapan yang tercetak di laporan dokumentasi.
🗜️ KUALITAS FOTO
Foto selalu dikompres sebelum disimpan. Makin hemat, makin lama penyimpanan perangkat bertahan bila sinkron cloud belum aktif.
☁️ SINKRON CLOUD (GOOGLE SHEETS)
Tempel URL Web App dari Google Apps Script agar data bisa dibuka di perangkat lain. Foto menu tersimpan di Google Drive.
Belum terhubung.
👥 AKSES PENGGUNA
Akuntan dan Ahli Gizi hanya dapat melihat dan mengunduh laporan, tidak dapat mengubah data. PIN bersifat pilihan — tanpa PIN, peran cukup dipilih saat membuka aplikasi. Catatan: ini pembatas peran agar tidak salah ubah, bukan pengamanan berlapis.
💾 CADANGAN FILE
Simpan seluruh data (isian harian, foto, daftar sekolah, pengaturan) ke satu berkas. Berguna untuk memindahkan data ke perangkat lain tanpa internet, atau berjaga bila data browser terhapus.
